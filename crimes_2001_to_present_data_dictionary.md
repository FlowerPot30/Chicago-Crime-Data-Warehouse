## Full Field List (Bronze Layer - As received from the API)
|#|Field Name (API)|Socrata Type|Description|Nullable|Notes/Common Issues|
|---|---|---|---|---|---|
| 1 | `id` | Number (Text) | Unique record ID generated by the Chicago Data Portal system | No | System-generated ID, not a business natural key (use `case_number` instead) |
| 2 | `case_number` | Text | Case number assigned by the Chicago Police Department (CPD) | No | **Primary natural key** of the dataset — duplicates have been observed (must dedupe in Silver) |
| 3 | `date` | Floating Timestamp | Date/time the incident occurred (approximate) | No | This is when the incident *happened*, not when the record was last touched — **do not use as watermark**, since old records that get corrected later would not be re-pulled |
| 4 | `block` | Text | Partial address (house number redacted for privacy) | No | Format example: `082XX S INGLESIDE AVE` |
| 5 | `iucr` | Text | Illinois Uniform Crime Reporting code | No | Join against an IUCR reference table to get standardized primary_type/description |
| 6 | `primary_type` | Text | High-level crime category | No | ~30+ distinct values (e.g. THEFT, BATTERY, NARCOTICS) — source for `dim_crime_type` |
| 7 | `description` | Text | Sub-category detail of the crime | No | A more granular breakdown of `primary_type` |
| 8 | `location_description` | Text | Type of location where the incident occurred, e.g. STREET, RESIDENCE, APARTMENT | Yes (some nulls) | Nulls occur when the location type wasn't clearly recorded |
| 9 | `arrest` | Boolean (Checkbox) | Whether an arrest was made | No | **Key field for SCD Type 2** — this value can change retroactively when a suspect is arrested later |
| 10 | `domestic` | Boolean (Checkbox) | Whether the incident was domestic-related | No | Used together with `arrest` in `dim_arrest_status` |
| 11 | `beat` | Text | Police patrol beat code (smallest police geography unit) | No | Part of `dim_location` |
| 12 | `district` | Text | Police district (larger than beat) | Yes (rare nulls) | |
| 13 | `ward` | Number | City council ward | Yes | Some older records may lack a value |
| 14 | `community_area` | Number | Community area code (77 community areas in Chicago) | Yes | Join against a community area reference table for full names if needed |
| 15 | `fbi_code` | Text | Crime classification per FBI (NIBRS) standard | No | Distinct from `iucr` — uses a different classification standard |
| 16 | `x_coordinate` | Number | X coordinate, Illinois State Plane East system | Yes | Frequently null together with `y_coordinate`, `latitude`, `longitude` |
| 17 | `y_coordinate` | Number | Y coordinate, Illinois State Plane East system | Yes | Same pattern as above |
| 18 | `year` | Number | Year the incident occurred (derived from `date`) | No | Already a derived field provided by the source |
| 19 | `updated_on` | Floating Timestamp | Date/time this record was last modified in the source system | No | **Used as the watermark column for incremental load**, and as the trigger for SCD Type 2 on `dim_arrest_status` |
| 20 | `latitude` | Number | Latitude (WGS84) | Yes | Null for some older or imprecisely located records |
| 21 | `longitude` | Number | Longitude (WGS84) | Yes | Same as latitude |
| 22 | `location` | Location (Point) | Object combining lat/long, GeoJSON-like format | Yes | Redundant with latitude/longitude — can be dropped in Silver to save storage |
